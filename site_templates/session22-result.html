How to make a submission (when a future file is approved)

  1. Download the approved all-finite (filename ends -allfinite.tif) GeoTIFF — whole array finite in [0,1], GDAL nodata tag unset. This specific combination is what avoids the portal error “Predicted values must be in range [0, 1]”: the strict validator used in this repo (variant_strict_whole_array_no_nan_allowed) fails on any NaN anywhere in the array, even legitimate NaN outside the competition footprint, and some portal validators appear to apply the same strict rule. A file whose name ends -nan.tif intentionally carries NaN outside the footprint (useful for local analysis/visual contrast) and is never the one to submit.
  2. Open the DrivenData competition → Make a submission → choose the single-band GeoTIFF (or a .zip containing exactly one).
  3. Paste the exact Note from the run card (≤140 chars) so the file is identifiable later.
  4. Confirm CRS/shape/geotransform match is automatic — files here are written from the sample-submission template and re-verified on read-back.
  5. Record the submission-page receipt (score + timestamp) back into registry/ — until then every number stays OWNER-REPORTED.

No file currently on this site is approved. Promotion is a separate selector step within the weekly cap shown on the submission page.

Method, canaries & audit trail

Lane: TMI horizontal-gradient ridge (band tmi_hg) and isostatic-gravity horizontal-gradient ridge (band iso_grav_anom_hg) of training_features.tif, skeletonised with the shared ridge_nms/ridge_strike_degrees utilities, endpoints paired across short gaps at matching strike (±20°) and bounded lateral offset — reused evaluator family (fresh HistGradientBoostingClassifier, same hyperparameters as prior sessions, retrained per fold) and reused shared writer/validator. Two emission variants were compared pre-registry-placement (union of both potential-field lanes' candidate pairs vs corroborated, requiring agreement from both lanes); union (42,480 dots) was chosen for the final file because it was denser and the sparser corroborated variant scored no better on the same canaries. Three experiments were used, exactly as budgeted: (1) leakage canary + pre-placement registry check, (2) final placement + post-placement registry/validator, (3) SegmentHoldout evaluation against a freshly retrained baseline. Named non-fault mimics: pipeline/transmission-line magnetic noise, vehicle/structure cultural magnetic anomalies, survey-line levelling seams, intrusive dike contacts crossing the gradient ridge, and coincidental ridge termination from a survey-boundary edge effect. No new external data was used or assumed; USGS/3DEP hosts are outside this sandbox's network allowlist, so any such extension remains explicitly deferred, not assumed obtainable.
