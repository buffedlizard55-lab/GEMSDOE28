3. How to submit when a file is approved (exact steps)

Use these steps only after a file's status is changed to OK TO SUBMIT: YES in the README and in the run card. None is approved today.

  1. Choose the file. Either the single-band GeoTIFF (.tif) or a .zip containing exactly one GeoTIFF with the same CRS, shape, and geotransform.
  2. Use a unique name. The name must not match any earlier entry. The pattern used here is gems29-<slug>-<date>-<content-id>-nan.tif. The current candidate's name is gems29-s29-hole-k20000-20261029-b68117a828cc-nan.tif.
  3. Add a short note (140 characters or fewer). Example style: clustering with k=25. The current draft note (not approved): S29 HGB hole-constrained k20000; unique under 70%/3px gate; holdout negative; NOT approved to submit (100 characters).
  4. Check the file first. Run scripts/verify_downloads.py and the gate scripts/s29_gate.py. Both must pass.
  5. Submit once per slot. Do not submit a file whose status is NOT OK. Do not copy an earlier submission.

Official rules, verified: NLR competition rules PDF · HeroX rules resource · DrivenData problem and metric page · public leaderboard.
