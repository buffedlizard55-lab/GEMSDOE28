Why the reported GEMSDOE32 candidate may have led this set

The strongest defensible explanation is about emission efficiency, not a proven geothermal-vent mechanism. Existing forensic pixel-set comparisons report that H33-2-B2 equals H27-4 solo-r1 after removing 2,545 catalogue-adjacent dots (distance ≤2 px), with no added dots. Under a distance-tolerant metric with a false-positive penalty, removing redundant predictions can improve the precision/recall trade-off if they contribute less hidden-truth coverage than false-positive cost. This is consistent with the raster relationship, but no organizer receipt proves it caused the reported 0.2778.

This does not show that adding geothermal indicators improves fault prediction. GEMSDOE36's larger set reportedly contains the GEMSDOE32 set plus 1,200 pixels and has a lower owner-reported score; that association alone does not isolate causality.
