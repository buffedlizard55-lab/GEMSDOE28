The exact path to an eligible submission

  1. Pass preflight before a scientific run. Configure the explicitly assigned lane, complete external registry and a frozen comparable holdout baseline. python scripts/check_run_preflight.py currently exits 1 with the real blockers. The existing data/cache and pinned shared tools now pass their local integrity checks.
  2. Use the shared evaluation path. Load the existing feature cache and read-only pinned shared evaluator/writer. Withhold whole fault segments/components with a buffer; construct catalogue features from visible faults only; mask those faults pixel-exactly. Never score a final full-catalogue TIFF as if it were an independent out-of-fold model.
  3. Run scientific gates in order. Test every feature alone, both polarities and each fold, before trusting it. Treat AUC above 0.90 as leakage until resolved. Check the surface against every registry member before placing dots. Stop and log a duplicate if correlation exceeds 0.90. On final dots also stop if more than 70% are within 3 pixels of any one member.
  4. Beat a frozen same-protocol baseline. Report pooled HOLDOUT-DTI with evaluator version, withheld-positive count and a 95% spatial-cluster interval. Require a positive paired improvement interval, not a mean-only improvement. The metric uses alpha 0.2, beta 0.8 and the 300 m triangular kernel. A projection is never a score.
  5. Serialize and independently re-read. The writer must produce one float32 GeoTIFF band on the exact sample CRS, shape and transform. Verify no NaN inside the footprint, values in [0,1], footprint handling, file SHA-256 and no catalogue overlap. A zero-outside variant has no NaN anywhere; that is a numeric-range property, not a guarantee of portal acceptance.
  6. Publish an eligible candidate, not a slot decision. Give it a content-bound unique name and a note of at most 140 characters. python scripts/check_promotion.py CARD.json checks the evidence schema, but does not authenticate its measurements, authorize an upload or inspect a TIFF by itself.
  7. Only the separate selector may use a real slot. It must check the actual current submission-page cap and remaining allowance. This review makes no selection. Account-side upload requires access that is not available here; no DrivenData automation occurs.
  8. At the competition form, only after all prior steps pass: choose the approved single-band .tif (or ZIP containing exactly that TIFF), paste its published ≤140-character note, and submit. Preserve the organizer's receipt bound to the exact filename/hash before labeling a result ORGANIZER-CONFIRMED. There is no approved file or portal note to copy today.
